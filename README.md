# New Mass Gen

Локальна Windows-платформа для пакетної генерації освітніх ілюстрацій через вебінтерфейс Gemini Create image. Oracle 0.21.6 керує окремими сесіями Chrome, а готові PNG/JPEG/WebP автоматично зберігаються у вибрану папку.

## Вимоги

- Windows 10/11;
- Google Chrome;
- Node.js 24 або новіший;
- доступ до Gemini з функцією Create image;
- інтернет для першого встановлення залежностей і генерації.

## Запуск

1. Розпакуйте архів у звичайну локальну папку.
2. Двічі клацніть `Відкрити.cmd`.
3. Під час першого запуску дочекайтеся встановлення залежностей.
4. Відкрийте `http://127.0.0.1:4188/`, якщо сторінка не відкрилася автоматично.

Альтернативний запуск із PowerShell:

```powershell
npm ci --ignore-scripts --no-audit --no-fund --cache .npm-cache
npm start
```

## Перше налаштування

1. У розділі «Папка зображень» виберіть повний шлях для результатів.
2. У полі «Основний стиль запиту» введіть власний опис стилю серії та натисніть «Зберегти налаштування».
3. Залиште режим «Прихований Chrome генератора» для роботи у фоні.
4. Додайте потрібні акаунти Gemini.
5. Для кожного акаунта натисніть «Увійти», завершіть вхід у Chrome, закрийте вікно та натисніть «Перевірити сесію».
6. Увімкніть акаунти й задайте їх порядок кнопками ↑/↓.
7. Виберіть затримку між запитами. Початкове значення — 30 секунд.

## Генерація

1. Виберіть діапазон понять або залиште його порожнім для всіх незавершених.
2. Виберіть розмір пакета.
3. Натисніть «Генерувати пакет».

Платформа створює зображення послідовно, пропускає наявні файли й працює на першому ввімкненому акаунті. Після повідомлення про ліміт вона переходить до наступного акаунта. «Пауза» завершує поточне зображення і зупиняє чергу; «Зупинити зараз» перериває поточну спробу.

Основний стиль можна змінювати у будь-який момент, коли пакет зупинений. Збережений текст застосовується до нових генерацій і повторів, але не змінює вже готові зображення. Натисніть на поняття у списку, щоб переглянути та скопіювати повний сформований запит перед запуском.

Нові зображення автоматично записуються у вибрану папку. Кнопка «Зберегти всі готові картинки» копіює туди доступні готові файли, яких ще немає, без нових запитів до Gemini та без перезаписування наявних файлів.

## Дані

- `input.csv` — початковий перелік понять;
- `scenes.json` — індивідуальні сцени;
- `.data/state.json` — локальний прогрес і налаштування;
- `.data/account-profiles/` — приватні сесії входу;
- `output/images/` — початкова папка результатів.

Папки `.data`, `.npm-cache`, `node_modules` і `output` створюються локально та не повинні потрапляти до публічних архівів. Не публікуйте браузерні профілі, cookies, журнали або згенеровані файли без окремої перевірки.

## Перевірка

```powershell
npm test
npm run check:background
```

Вебінтерфейс Gemini, доступність моделей і ліміти можуть змінюватися. Після оновлення Chrome, Gemini або Oracle перевірте один тестовий пакет перед масовою генерацією.
